# Anonymous Supplementary Code

This repository contains the code used to reproduce the experiments and results reported in the paper submitted to AISTATS 2027.

## Setup

The R scripts use the `here` package for project-relative file paths. Therefore, please open and activate the provided `band.Rproj` project in RStudio before running the scripts. This ensures that all required source files are located correctly.

## Contents

* `loglikelihood.R` — Reproduces the log-likelihood comparisons reported in **Section 5.5**.
* `u_shaped_bias.R` — Reproduces the U-shaped log-likelihood profile experiment reported in **Section 5.4**.
* `real_data_experiments.R` — Reproduces the real-data experiments reported in **Section 6**.

The supplementary code is provided for anonymous peer review.
